# 수비 화면 구장 그림 (지피티 픽셀아트)

1. 지금 코드 구장 그림(`view.ts fieldBg` 코드 그림, 확대용 1575×886)을 1536×864 로 뽑아 「구장 배치」 이미지로 씀 (선수 · 공 없음)
2. 지피티에 「화풍 기준(통과한 주자 달리기 시트) + 구장 배치」 두 장 + `prompt.txt` → 같은 배치 그대로 픽셀아트로
3. `python3 clean.py 지피티그림.png 구장배치.png 출력폴더` — 배치 맞춤(ECC 아핀, 베이스 · 파울폴 오차 1~3px), 보통 788×443 · 확대 1575×886, 72색 고정 팔레트, 흰 선 · 베이스는 흰색 유지
4. `field_bg.webp` · `field_bg_hd.webp` → `public/baseball/field/`

게임: 그림을 받으면 코드 그림 대신 씀 (밤 경기는 위에 어둡게 한 겹). 공 · 그림자 · 점선은 같은 픽셀 크기로 코드가 그림 (`pixelDraw.ts`)
